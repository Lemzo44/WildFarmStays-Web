# Create Repository on GitHub First

## Step-by-Step:

### Step 1: Create Repository on GitHub (Web)
1. Go to **https://github.com/new**
2. Fill in:
   - **Repository name**: `wildfarmstaysweb` (no hyphen!)
   - **Description**: `WildFarmStays Web Application`
   - **Visibility**: Public or Private (your choice)
   - **DO NOT** initialize with README, .gitignore, or license
3. Click **Create repository**

### Step 2: Go Back to GitHub Desktop
1. In GitHub Desktop, click **File** → **Add Local Repository**
2. Navigate to: `C:\Users\paull\Documents\GitHub\WildFarmStays-Web`
3. Click **Add Repository**

### Step 3: Connect to Existing Repository
1. GitHub Desktop will show "This directory isn't a Git repository yet"
2. Click **"Choose..."** to create a repository here
3. After creating the local repo, click **Publish repository**
4. Now you should see the option to **"Publish to GitHub"**
5. It should show your new repository `wildfarmstaysweb`
6. Click **Publish**

## Alternative: Change Folder Name
If that doesn't work, rename your folder:
1. Close GitHub Desktop
2. Rename folder from `WildFarmStays-Web` to `wildfarmstaysweb`
3. Open GitHub Desktop
4. Add Local Repository → select the renamed folder
5. Publish
